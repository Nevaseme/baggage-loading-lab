# Submission bundles

Create one directory per submission: `YYYY-MM-DD-technique/`. Add `-r2`, `-r3`,
etc. for repeated submissions on the same date. Keep its exact ZIP,
`result-log.txt`, hashes, and a short README together. Never overwrite an earlier
submission's feedback. A second result for the same ZIP gets its own submission
folder and evaluation record; artifact identity remains content-addressed.
